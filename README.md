# 네이버 블로그 글 자동생성기

키워드와 업체 정보를 입력하면 SEO/AEO/GEO, E-E-A-T를 고려한 네이버 블로그 글 초안(제목/본문/태그)을 자동으로 생성해주는 도구입니다. 사용자가 직접 발급받은 Google (Gemini) API 키를 입력해 사용하며, 생성된 글은 검토 후 직접 복사하여 등록하는 용도입니다.

## 특징

- 메인/연관 키워드, 어조(친근한 블로그체 / 전문적·분석적 / 내돈내산 후기체 / 정보전달형), 분량, 하단 문구를 입력받아 글을 생성
- 업체/상품 정보(업체명, 주소, 전화번호, 영업시간, 주요 서비스, 주차 여부, 지도 URL, SNS)를 본문에 자연스럽게 반영
- Google API 키는 브라우저에만 저장되며, 요청 시 서버(`/api/generate`)를 통해 Gemini API로 전달될 뿐 서버에 저장되지 않음

## 설치

```bash
npm install
```

## 개발 서버 실행

```bash
npm run dev
```

`http://localhost:3000` 에서 확인할 수 있습니다.

## 프로덕션 빌드

```bash
npm run build
npm run preview
```
